OpenImport¶

Import and export for Magento 2 and Mage-OS, free and MIT.

OpenImport puts profiles, column mapping, value transforms, a dry run that previews every change, schedules and remote sources (SFTP, FTP, URL, server folder) in front of Magento's own import engine. Magento does the writing, so imported data is exactly what core import would produce, and upgrades keep working.

Install¶

composer require iranimij/openimport
bin/magento module:enable Iranimij_Base Iranimij_OpenImport
bin/magento setup:upgrade

Magento Open Source 2.4.7 to 2.4.9 or Mage-OS, PHP 8.2 to 8.4. Magento's cron must run for schedules and queued runs; bin/magento openimport:doctor tells you whether it does.

Getting help¶

Open an issue at github.com/iranimij/openimport with a 10-row sample of your file and the run's message. Security problems: see SECURITY.md.
